# Pandur II - WebGL

WebGL experiment where you are able to rotate and activate a 3D wireframe visualization of the [PandurII](https://en.wikipedia.org/wiki/Pandur_II) vehicle.


This experiment uses the JavaScript 3d engine [Three.JS](https://github.com/mrdoob/three.js/).

## GitHub pages hosted version

There are 2 versions, one using Three.js and the other using Babylon.js

- Using Three.js [https://crei0.github.io/pandur_ii_webgl/](https://crei0.github.io/pandur_ii_webgl/)
- Using Babylon.js [https://crei0.github.io/pandur_ii_webgl/babylonjs/pandur.html](https://crei0.github.io/pandur_ii_webgl/babylonjs/pandur.html)
